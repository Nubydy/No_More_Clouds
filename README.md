# No_More_Clouds
This mod takes away the clouds on the Map and Mini-Map on the game Valheim. Mod is made out of spite of the clouds and not being able to see the map fully. Fully client side mod, no need to put on server. This is my first ever mod of any game so please be patient if there are any bugs that you encounter. If you find a bug please report them to me on discord.

# Installation
Copy the contents of "plugins" into your plugins folder in your BepInEx/plugins directory. It should just be able to be downloadable on Thunderstore and Vortex mod managers on the clients themselves :)
